# Вычислительное ядро

Каталог `mesh_repair_blender/core` перенесён из **MeshRepair 1.0.0**, commit
[`6ca780f`](https://github.com/modeco46/MeshRepair/commit/6ca780f). С версии аддона 1.1.2 поверх него применены
локальные исправления (`engine_revision: blender-1.1.2` в JSON):

- предел общего числа вокселей заменён предупреждением для расчёта по слоям; предварительная проба ограничена
  по размеру, а её оценка относится только к восстановлению, не ко всему ремонту;
- небольшие пересечения восстановленной поверхности сначала исправляются локальной релаксацией с ограничением
  смещения; неизменная топология позволяет доказать предел для всех точек поверхности по смещению вершин;
- если этот путь не прошёл проверку, сохранены прежние Relax/CutAndFill с откатом и проверкой расстояния;
- микротрещины Marching Cubes закрываются только с доказанным расстоянием новых граней до старой границы;
- при небольших остаточных дефектах выполняется максимум один повтор с более точным winding (beta 4 вместо 2),
  без увеличения шага, с сохранением CPU/CUDA обработки по слоям и полной проверкой результата;
- частичный отчёт сохраняется при исключении, устройство для этапов расчёта по слоям указывается правильно.

Не перенесены Qt/VTK GUI, отдельный viewport, темы, виджеты и код запуска desktop-приложения. Blender отвечает за
сцену, отображение и сохранение `.blend`; `worker.py` сохраняет изоляцию вычислений, прогресс и остановку процесса.

При обновлении ядра нужно синхронно перенести `compute.py`, `deviation.py`, `engine.py`, `holes.py`, `inspection.py`,
`orientation.py`, `planes.py`, `reduction.py`, `reporting.py`, `storage.py`, обновить commit выше, сохранить или
пересмотреть перечисленные исправления и выполнить тесты.
