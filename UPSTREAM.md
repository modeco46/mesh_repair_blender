# Вычислительное ядро

Каталог `mesh_repair_blender/core` перенесён из **MeshRepair 1.0.0**, commit
[`6ca780f`](https://github.com/modeco46/MeshRepair/commit/6ca780f). С версии аддона 1.1.2 поверх него применены
локальные исправления (`engine_revision: blender-1.2.0` в JSON тестовой ветки):

- предел общего числа вокселей заменён предупреждением для расчёта по слоям; предварительная проба ограничена
  по размеру, а её оценка относится только к восстановлению, не ко всему ремонту;
- небольшие пересечения исправляются с сохранением проверенных промежуточных улучшений: каждый следующий
  проход обрабатывает остаточные дефекты. Совокупное смещение проверяется относительно начальной поверхности;
- начальный предел локального изменения — ¼ шага, для не более 64 оставшихся пересекающихся граней — ½ шага;
- при неизменной топологии используется доказательство через смещение вершин, при изменении связности —
  доказательство только изменённых участков с точным исключением неизменённых граней;
- добавлена локальная очистка вырожденных рёбер; сохраняются Relax/CutAndFill, откат и проверки оболочек;
- уже предусмотренное удаление воксельных полостей и выбранных мелких оболочек применяется до локального
  ремонта дефектной реконструкции. Пересечения оставшейся поверхности заново проверяются;
- микротрещины Marching Cubes закрываются только с доказанным расстоянием новых граней до старой границы;
- полный повтор winding beta 4 по умолчанию выключен: CUDA-вызов может долго не возвращать управление callback.
  Внутренний параметр `accurate_winding_max_seconds` оставлен для явно запрошенных экспериментов;
  его кооперативный предел не гарантирует остановку нативного вызова точно в заданную секунду;
- финальный проход по копланарным граням сохраняет углы; до 2 млн граней он выполняется без разбиения,
  выше — нативно параллельно. Итоговый допуск проверяется относительно сетки до всех проходов упрощения;
- частичный отчёт сохраняется при исключении, устройство для этапов расчёта по слоям указывается правильно.

В тестовой 1.2.0 дополнительно: пакетное чтение идентификаторов компонент с проверкой ABI и резервным путём;
локальный ремонт отдельных оболочек перед Union; ремонт небольшого остатка пересечений после децимации;
защита областей превышения допуска с переносом через PackMapping; поиск поверх уже принятой сетки;
выборочная статистика плоскостей и отдельный учёт удалённых оболочек. Передача результата Blender использует
проверенные индексированные массивы, сохраняя связность без промежуточного STL. Полные проверки топологии
и пересечений сохранены. Подробности и проверенные ограничения: [PERFORMANCE_1_2.md](PERFORMANCE_1_2.md).

Не перенесены Qt/VTK GUI, отдельный viewport, темы, виджеты и код запуска desktop-приложения. Blender отвечает за
сцену, отображение и сохранение `.blend`; `worker.py` сохраняет изоляцию вычислений, прогресс и остановку процесса.

При обновлении ядра нужно сопоставить весь каталог `core`, включая новые `components.py`, `hotspots.py`,
`surface_paths.py`, `transfer.py`, обновить commit выше, сохранить или пересмотреть перечисленные исправления
и выполнить тесты.
