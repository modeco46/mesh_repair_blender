# 1.4.1 — ремонт крупных сеток в Blender 5.3, Windows x64

- Для повреждённых исходников от 1 млн треугольников выбран прямой путь от согласования нормалей
  и закрытия дыр к вокселизации. Команда ремонта пропускает полный подсчёт пар пересечений исходника,
  повторную попытку неудачной заплатки и долгие локальные операции Boolean/CutAndFill на повреждённой сетке.
- Когда заплатка замыкает исходно открытую оболочку, проверяется знак её объёма. Для вывернутой
  оболочки разворачиваются грани. Дополнительный ремеш уже исправного тела не требуется.
- Для одной закрытой оболочки добавлен поверхностный ремеш OpenVDB на CPU. В местах самокасания
  применяется симметричное воксельное замыкание с радиусом 0,35 шага. Результат должен сохранить
  число сквозных отверстий и пройти проверку расстояний в обе стороны. При отказе, открытых контурах
  и пересечении отдельных оболочек доступен прежний winding, включая CUDA.
- Для общего упрощения поверхностей от 1 млн граней введён консервативный начальный проход.
  Дальнейшая децимация работает на уже уменьшенной сетке. При отказе ограничено число повторов
  на полном разрешении. Верификация использует исходную поверхность до всех проходов.
- При большой воксельной реконструкции удаление предусмотренных политикой артефактов предшествует
  проверке самопересечений. Локальная правка получает уже найденные пересекающиеся грани.

Контрольная модель — синтетическое кольцо с самопересечением, двумя пропусками и перевёрнутым
участком, 2 159 998 треугольников. При допуске 0,01 мм на одном CPU рабочий процесс 1.4.0
занял 101,3 с, в 1.4.1 — 34,6 с. Измеренное максимальное расстояние от исходных вершин до
итоговой поверхности уменьшилось с 0,3700 до 0,00974 мм. В 1.4.1 получены 43 988 треугольников,
одно сквозное отверстие, ноль открытых краёв и ноль самопересечений. Время зависит от геометрии
и оборудования.

На варианте того же теста из 50 248 треугольников поверхность на шаге 0,01 мм также вырастает
до миллионов граней. Полный ремонт занял 16,6 с вместо 97,6 с, максимальное измеренное
отклонение исходных вершин составило 0,00952 мм. Это отдельный контрольный STL.

# 1.4.0 — Windows x64, Blender 5.3

Версия подготовлена от 1.1.3 для проверки на пользовательских моделях.

- Исправлена потеря объёма и ошибки при наличии перевёрнутой копии грани или треугольника нулевой площади.
  Общие контактные грани отдельных замкнутых тел оставляются для Boolean. Для полностью плоского исходника
  выводится причина и подсказка о толщине.
- Плоские контуры с подтверждённой опорной геометрией закрываются без сглаживания стенок.
  Кольцевой торец строится с учётом внутреннего контура. Проверяются площадь, сохранение вершин,
  замыкание контура и пересечения.
- Для подходящих сборок из 33–128 оболочек добавлено точное групповое объединение перед вокселизацией.
  Обязательны проверка операндов, замкнутость результата, отсутствие пересечений, контроль объёма
  и расстояний до поверхности. При отказе остаётся штатный путь вокселизации при том же шаге.
- Децимация проверяет число оболочек, суммарное число туннелей, изменение объёма до 2% и прежний предел
  расстояния относительно поверхности до всех проходов. После трёх неудачных свободных размещений
  можно выполнить одну попытку на исходных вершинах. Количество поисковых проходов не увеличено.
- Blender получает проверенную сетку в виде пар массивов с точной сверкой координат и индексов после записи.
  Убраны промежуточный экспорт STL и две загрузки результата из STL при обычном ремонте в Blender.
  Карта отклонений по кнопке и Flat Shade сохранены. Допуск по умолчанию 0,02 мм.
- Ускорены обработка одной оболочки и проверка внутренних вершин. На больших результатах ограничен
  объём расчёта справочной статистики плоскостей. Панель показывает текущий этап и время.
  При остановке можно сохранить JSON с состоянием прерванного запуска.

Контрольные примеры при включённых настройках панели:

Порядок локальной очистки и закрытие коротких контуров сверены с исходниками MeshLab 2025.07.

объём 8 мм³. Это сравнение отдельных операций. Ремонт архангела и иконы требует повторной проверки
на исходных моделях. Устанавливайте ZIP Windows x64 через Install from Disk и перезапускайте Blender.

# 1.1.3

- Убран автоматический полный повтор winding beta 4: CUDA могла не возвращать управление callback несколько
  минут, и ограничение времени не обеспечивало своевременную остановку.
- Локальный ремонт сохраняет промежуточные улучшения и продолжает с остаточными пересечениями. Добавлена
  очистка вырожденных рёбер в области дефекта. Допуск не накапливается между попытками: он проверяется
  относительно начальной восстановленной поверхности (¼ шага, для небольшого остатка — не более ½ шага).
- Доказательство расстояния после локального изменения связности обрабатывает только изменённые участки;
  неизменённые грани исключаются по точному совпадению. Проверки замкнутости, оболочек и пересечений сохранены.
- Удаляемые по действующей политике воксельные полости и мелкие оболочки больше не блокируют локальный ремонт:
  они очищаются раньше, затем оставшаяся сетка заново проверяется.
- Добавлен финальный проход по копланарным граням, работающий также вместе с общим упрощением. Сохраняются
  углы, проверяется общий допуск относительно сетки до упрощения; при неудаче выполняется откат.
- Flat Shade, допуск по умолчанию 0,02 мм, CUDA и нативная многопоточность сохранены. Сборка только Windows x64.

Регрессии включают последовательное исправление нескольких дефектов, доказательство изменённых участков,
финальное сокращение плоской коробки с 2012 до 12 треугольников без изменения формы и откат после ошибки экспорта.
Время полного ремонта конкретной модели зависит от геометрии; JSON без исходной сетки не позволяет его замерить.

Установка: ZIP windows-x64 через Install from Disk, затем перезапуск Blender.

# 1.1.2

- Убран ошибочный отказ при более чем 6 млрд вокселей для расчёта по слоям. Размер предварительной пробы
  ограничен; оценка времени относится к вокселизации, а не ко всему ремонту. Выбранный допуск не увеличивается.
- Добавлено локальное исправление остаточных пересечений с ограничением перемещения вершин до ¼ допуска
  и проверкой всей поверхности при неизменной топологии. Сохраняются проверка замкнутости, количества оболочек,
  отсутствия пересечений и прежние резервные методы. Непроверенная сетка не выдаётся за успешный результат.
- Добавлено закрытие микротрещин Marching Cubes с проверкой новых граней относительно прежней границы.
- Если небольшие дефекты остались, выполняется один повтор с более точным winding при том же допуске;
  результат снова проверяется. Вычисление поля этого повтора ограничено 180 секундами через callback MeshLib;
  проверка результата требует дополнительного времени. Основной проход этим лимитом не ограничивается.
- При ошибке сохраняется подробный JSON текущего запуска, включая причины отклонения исправлений и журнал.
  При аварийном завершении нативного процесса сохраняются код выхода и доступный журнал.
- Исправлено указание CUDA в таймингах этапов расчёта по слоям.
- Исправленная модель явно получает Flat Shade. Допуск по умолчанию остаётся 0,02 мм.
- Сборка, проверки и публикация выполняются только для Windows x64.

Проверки включают реальные CPU-расчёты MeshLib при 0,01 / 0,011 / 0,015 / 0,02 мм и тест локального
исправления 196 пересекающихся граней с сохранением 50 оболочек. Аппаратная производительность CUDA
этими CPU-тестами не измеряется.

Установите ZIP windows-x64 через Install from Disk и перезапустите Blender.

# 1.1.1

- Исправлена ошибка `AttributeError: 'Event' object has no attribute 'timer'` в Blender 5.3.
  Проверка, ремонт и построение карты отклонений обрабатывают события таймера без обращения
  к отсутствующему свойству; прогресс и завершение задания обновляют панель автоматически.
- Проверки прогресса и завершения всех трёх операций используют событие без свойства `timer`,
  как в API Blender. Допуск по умолчанию остаётся 0,02 мм.

При обновлении с 1.1.0 перезапустите Blender, чтобы завершить обработчик старой версии.

# 1.1.0

- Панель обновляется при запуске, на каждом таймере прогресса и по окончании задания без дополнительного клика.
- Единицы сцены автоматически переводятся в мм; выбор единиц удалён. Допуск по умолчанию — 0,02 мм.
- «Проверить» сверху, информация по одному показателю на строку, крупная кнопка ремонта снизу.
- Все дополнительные параметры и отчёт находятся внутри свёрнутых «Расширенных настроек».
- По умолчанию включены схлопывание, упрощение, склейка близких вершин, удаление мелких оболочек и скрытие исходников.
- «Посмотреть отклонения» строит цветовую карту на исправленном объекте: 0 → допуск → 2 допуска.
  Расчёт в отдельном worker сохраняет CUDA/CPU fallback. Выключение карты возвращает прежний режим отображения.
- Карта измеряет вершины результата относительно исходных треугольников и сохраняется в атрибутах `.blend`.
  Она фиксирует состояние ремонта; редактирование модели не пересчитывает карту автоматически.

Установка: скачайте ZIP своей платформы из этого релиза и установите через Blender → Preferences →
Extensions → Install from Disk. При обновлении перезапустите Blender. Явно заданные настройки существующей
сцены сохраняются; новые значения по умолчанию используются для незаданных параметров.
