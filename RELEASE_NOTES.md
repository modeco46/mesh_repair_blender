# 1.1.0

- Панель обновляется при запуске, на каждом таймере прогресса и по окончании задания без дополнительного клика.
- Единицы сцены автоматически переводятся в мм; выбор единиц удалён. Допуск по умолчанию — 0,02 мм.
- «Проверить» сверху, информация по одному показателю на строку, крупная кнопка ремонта снизу.
- Все дополнительные параметры и отчёт находятся внутри свёрнутых «Расширенных настроек».
- По умолчанию включены схлопывание, упрощение, склейка близких вершин, удаление мелких оболочек и скрытие исходников.
- «Посмотреть отклонения» строит цветовую карту на исправленном объекте: 0 → допуск → 2 допуска.
  Расчёт в отдельном worker сохраняет CUDA/CPU fallback. Выключение карты возвращает прежний режим отображения.
- Карта измеряет вершины результата относительно исходных треугольников и сохраняется в атрибутах `.blend`.
  Она фиксирует состояние ремонта; редактирование модели не пересчитывает карту автоматически.

Установка: скачайте ZIP своей платформы из этого релиза и установите через Blender → Preferences →
Extensions → Install from Disk. При обновлении перезапустите Blender. Явно заданные настройки существующей
сцены сохраняются; новые значения по умолчанию используются для незаданных параметров.
